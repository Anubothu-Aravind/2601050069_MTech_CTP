# 2601050069_MTech_AlgorithmicProgramming_CO1

This repository contains coursework and implementations for the Master of Technology (M.Tech) Algorithmic Programming / Computational Thinking and Programming (CTP) syllabus.

## Overall Purpose
The repository serves as a structured portfolio for designing, implementing, and analyzing fundamental algorithms. The work is organized systematically by Course Outcomes (CO1 to CO6) to demonstrate algorithmic proficiency, optimization, and software development practices.

## Organization of Work
1. **Course Outcomes (`COx/`)**: Each module is organized inside its respective directory, detailing specific curriculum targets.
2. **Algorithm Subfolders**: Complex design paradigms under a Course Outcome (such as `CO1/DivideAndConquer/`) are grouped in thematic subdirectories.
3. **Structured Documentation**: Every algorithm subfolder has a dedicated `readme.md` detailing the problem statement, abstraction, step-by-step algorithm, complexity analysis, and implementation details.
