# Banking Ledger — OOP Domain Model
Demonstrates: Abstraction, Inheritance, Polymorphism, Encapsulation, Dataclasses, Type Hints.
| Pattern | Applied In |
|---------|-----------|
| Inheritance | SavingsAccount, CurrentAccount extend Account |
| Polymorphism | withdraw() behaves differently per account type |
| Encapsulation | __balance private, exposed via property |
