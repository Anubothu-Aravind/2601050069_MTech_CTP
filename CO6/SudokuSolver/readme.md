# Sudoku Generator & Solver — AI Pair Programming Project
~3000 LOC project built with AI pair tooling (Antigravity IDE / Claude).
## Techniques Used
- Backtracking with Branch-and-Bound pruning (CSP + MRV heuristic)
- OOP domain model (Board, Solver, Generator, Grader)
- Property-based testing with Hypothesis
- CI/CD: GitHub Actions → GitHub Pages deployment
- Live demo: https://anubothu-aravind.github.io/pyodide-sudoku
