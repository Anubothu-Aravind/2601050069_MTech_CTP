# Course Outcome 1 (CO1) — Divide and Conquer

This section covers algorithms and techniques designed around the **Divide and Conquer** algorithmic paradigm.

## Overview
The Divide and Conquer strategy is a fundamental design paradigm in computer science. It works by breaking a problem down into two or more subproblems of the same or related type, solving these subproblems recursively, and then combining the solutions to solve the original problem.

## Objectives / Topics
- Understand the core principles of the Divide and Conquer design paradigm.
- Learn how to analyze the time and space complexity of recursive algorithms using Master Theorem or recursion trees.
- Implement search and sorting algorithms using Divide and Conquer.
